# Mine_Game_Server

Socket.IO-based server prototype for a Mines-style gambling game, developed in Node.js.

This project was created as a practical application of the knowledge acquired during my postgraduate studies in Systems Analysis and Development. It demonstrates concepts such as real-time client-server communication, game state management, backend logic, random mine generation, player interaction flow, and basic web integration.

The main goal of this repository is to document and showcase my technical learning process through the development of a functional game server prototype.

## How to run

1. Run `Server.js`
2. Open the local page:

```txt
http://localhost:2108/page/
```
